# CertMgmt Web

This folder contains the rewritten C# ASP.NET Core web-based replacement for the original PowerShell certificate management UI.

## Run

1. Open `CertMgmtWeb` in a .NET-capable IDE.
2. Restore and run the project.
3. Open the browser to the site root.

## Features

- List ADCS enrollment CAs
- Load CA templates
- Upload and inspect CSR files
- Submit CSRs to ADCS
- Retrieve issued certificates
- View and approve/deny pending requests
