# CertMangement
Little Front End for ADCS to submit/retrieve/Issue and deny certificates/requests
written in Powershell v5
allows enrollment control and certificate handling for ADCS

## C# Web Version
A new C# ASP.NET Core web service has been added under `CertMgmtWeb/`.
This version exposes a browser-based UI and reimplements the same CA operations and CSR handling.
